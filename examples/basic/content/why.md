This site is its own documentation. Every page is a markdown file of quotes, built by quotebook.

> Turn a folder of markdown files
> into a quiet quotes website.
>
> — the one-line pitch

> The passages you keep deserve better than a notes app:
> a page with room to breathe,
> and a link you can share.
>
> — why it exists

> One file per book.
> One blockquote per quote.
> That is the whole format.
>
> — the design
<!-- tags: format -->

> No framework. No web fonts.
> JavaScript only when you ask for slides.
>
> — the output
<!-- tags: output -->

> Light when the world is light,
> dark when it is dark.
>
> — on themes
<!-- tags: design -->

> Every quote has an address.
> Click its number and the address bar points right at it.
>
> — on permalinks
<!-- tags: design -->
