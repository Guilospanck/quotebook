Four steps, one per screen.

> Scaffold a config, an example book
> and a GitHub Pages workflow:
>
> ```sh
> npx quotebook init
> ```
>
> — step one

> Write. Every markdown file in `content/`
> becomes a book on the home page.
>
> — step two

> Preview it, with live reload:
>
> ```sh
> npx quotebook dev
> ```
>
> — step three

> Push to `main`. Once, in Settings → Pages,
> set the source to GitHub Actions.
> Every push after that publishes itself.
>
> — step four

> That's it.
> The page you are reading was made the same way.
>
> — the end
